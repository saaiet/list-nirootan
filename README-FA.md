# وب‌سایت نیروتن | NIROOTAN

وب‌سایت فارسی، راست‌چین و واکنش‌گرا، ساخته‌شده به صورت **کاملاً استاتیک** برای GitHub Pages یا هاست عادی.

## فایل‌ها
- `index.html`: صفحه اصلی و متادیتا
- `assets/style.css`: طراحی و رنگ‌ها
- `assets/script.js`: منو، کپی شماره‌ها و انیمیشن نمایش
- `assets/nirootan-logo.webp`: لوگوی افقی از فایل ارسالی
- `assets/nirootan-mark.webp`: نشان اصلی از فایل ارسالی
- `assets/favicon.png`: نشان تب مرورگر
- `fonts/`: فایل‌های دارای مجوز فونت پیدا با ۹ وزن

## نصب روی GitHub Pages
۱. مخزنی عمومی به نام `nirootan` (یا هر نام دلخواه) بسازید.
۲. محتویات این ZIP را در **ریشهٔ** مخزن آپلود کنید (فایل `index.html` باید در ریشه باشد).
۳. از Settings → Pages، گزینه `Deploy from a branch` و سپس `main` و `/ (root)` را انتخاب کنید.
۴. بعد از انتشار آدرس سایت `https://saaiet.github.io/nirootan/` خواهد بود، به شرطی که نام مخزن `nirootan` باشد.

## فونت پیدا
فونت اصلی `PeydaWeb` با فایل‌های ارائه‌شده از طرف صاحب سایت در هر ۹ وزن به صورت محلی استفاده می‌شود. استفاده از فایل‌های فونت و انتشار آن‌ها تابع مجوز فونت است.

## فونت پیدا
